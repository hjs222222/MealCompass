== 怎么用这份数字 ==
  1. README 里 hybrid_rerank 的 R@10 必须写成区间，不能给三位小数的单一值；
  2. 任何一次跑的 `provider_stats.degraded_calls != 0` 都必须丢弃重跑（走了本地兜底/降级回 RRF，数字不可比）；
  3. `vector` / `hybrid` 不存在这个抖动，可复现到小数点，两者不要混在一句话里说。
